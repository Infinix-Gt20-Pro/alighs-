# ALIGH'S WARE — Standalone Frontend

Luxury 3D Eyewear Platform & Optometry Consultation Booking (Frontend UI).

## 🚀 Quick Start

1. Install dependencies:
```bash
npm install
```

2. Run Next.js frontend:
```bash
npm run dev
```
Open `http://localhost:3000`.

## 📦 Features:
- 3D Real-time CAD Glasses Hero Model (Three.js / React Three Fiber)
- Exploded View Component Mechanics with Scroll Animation
- Magic Lens Reveal with 8K Photorealistic Clarity
- AI Face-Shape Frame Selector
- Doctor Consultation Booking for Dr. Sheeraz Ahmad
- Luxury Filterable Catalog (/shop)
- Interactive Product View with Custom Colors (/shop/[slug])
- Full Cart Drawer & Multi-Step Checkout Flow
